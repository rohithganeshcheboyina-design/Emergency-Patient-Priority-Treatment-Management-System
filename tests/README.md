# Test Suite & Quality Assurance Documentation

The **Hospital Emergency Patient Priority Treatment Management System** employs a comprehensive, multi-tiered testing strategy spanning unit tests, integration tests, E2E workflow simulations, and security penetration test suites.

## Test Suite Architecture

```text
tests/
├── unit/           # Business logic, PriorityQueue comparator, validation, state machine
├── integration/    # Service-to-DAO integration, Bed & Appointment allocation, RBAC
├── e2e/            # Complete clinical lifecycle simulations, SQL injection & security penetration
└── README.md       # Quality metrics and test execution instructions
```

> **Note**: Test source code is located in `src/test/java/com/hospital` to adhere to standard Maven testing conventions (`mvn test`). This directory documents the test coverage, execution matrix, and QA design.

## Execution Commands

### Run Full Test Suite:
```cmd
mvn clean test
```

### Run Specific Test Suite:
```cmd
# Run E2E Workflow Test
mvn test -Dtest=EndToEndHospitalWorkflowTest

# Run Security & Penetration Tests
mvn test -Dtest=SecurityAndInjectionTest

# Run Priority Queue Triage Unit Tests
mvn test -Dtest=PriorityQueueManagerTest
```

### View Test Reports:
HTML and XML test reports are generated by the Maven Surefire Plugin in:
```text
target/surefire-reports/
```
